# دليل القاصد

دليل علمي وعملي متكامل للقاصد إلى المسجد النبوي: من دخول المسجد النبوي، إلى السلام على رسول الله ﷺ وصاحبيه، ثم الصلاة والذكر والدعاء في الروضة الشريفة.

موقع ثابت (HTML / CSS / JavaScript) باللغة العربية بالكامل، بواجهة من اليمين إلى اليسار، ومصمّم أولًا للجوّال.

## أقسام الدليل

1. **زيارة المسجد النبوي والصلاة فيه** — الأساس الشرعي للزيارة، وآداب ما قبل الدخول ودخول المسجد، وتحية المسجد، وبطاقة جيب، والمسار الكامل.
2. **السلام على النبي ﷺ** — آداب المواجهة الشريفة، وصيغ السلام على النبي ﷺ ثم على أبي بكر وعمر رضي الله عنهما، وما ينبغي تجنّبه.
3. **الصلاة في الروضة الشريفة** — فضل الروضة ومعلوماتها، وفضل الصلاة فيها، وحدودها، وتنظيم الدخول والمواعيد، والأدعية، وأقوال العلماء، وأكثر الأخطاء شيوعًا.

## المزايا

- تصميم أنيق وهادئ مستوحى من القبة الخضراء (أبيض وأخضر فاتح).
- **وضع نهاري / ليلي** مع حفظ اختيار المستخدم والاعتماد على إعداد الجهاز افتراضيًا.
- تصميم متجاوب (mobile-first) يعمل على الجوّال واللوحي والحاسوب.
- خطوط عربية: **Noto Naskh Arabic / Amiri** للأدعية و**Tajawal** للواجهة.
- بطاقات أدعية مميّزة، وجداول منظّمة، وخطوات مرقّمة، ومعرض صور.
- تحميل تدريجي للصور مع ظهور ناعم، وزرّ العودة للأعلى، وقائمة جوّالة منسدلة.
- إتاحة وصول جيدة: عناوين منظّمة، وسم بديل للصور، وتباين مريح.

## هيكل المشروع

```
├── index.html            # الصفحة الرئيسية
├── visit-mosque.html     # القسم الأول
├── greeting.html         # القسم الثاني
├── rawdah.html           # القسم الثالث
├── assets/
│   ├── css/style.css     # الأنماط
│   ├── js/main.js        # السلوك التفاعلي
│   └── img/              # الصور المستخدمة
└── source/               # المستند الأصلي والصور الأصلية
```

## التشغيل محليًا

افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا بسيطًا:

```bash
python -m http.server 8000
```

ثم تفضّل إلى: `http://localhost:8000`

## المصدر

أُخذ محتوى الموقع من المستند المرفق في مجلد `source`، ونُقل نصّه كما هو دون إضافة أو تغيير في الأحكام أو الأدعية.
